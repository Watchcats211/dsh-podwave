# 实时字幕（听系统声音）

顶栏「实时字幕」：听电脑**正在播放**的声音，一句一句滚出原文和中文。跟媒体库里的单集无关，
YouTube、直播、在线会议、任何播放器都能用。

## 它是怎么工作的

```
系统声音 ──▶ 虚拟声卡（BlackHole / VB-Cable）──▶ 浏览器 getUserMedia
   │                                              │
   │                                    16kHz 单声道 PCM
   │                                              ▼
   │                                    能量 VAD 切句（600ms 静音断句，12s 封顶）
   │                                              ▼
   │                                    每句编码成 WAV ──▶ 宿主
   │                                                        │
   │                                          DeepSeek /v1/tools/asr（识别）
   │                                                        │
   │                                          当前翻译引擎（默认 DSH 模型）
   │                                                        ▼
   └──────────────────────────────────────────── 悬浮窗逐句显示
```

- **浏览器拿不到「系统输出」本身**，所以插件用两种办法绕开：macOS 14.2+ 直接走系统音频采集
  （recommended，见下节）；其它情况把声音同时送到扬声器和一块虚拟声卡（多输出设备）。
- **识别走云端**（约 ¥0.4/小时）。本地 MOSS / Qwen3-ASR 在一句话的粒度上要 1.5~7 秒才出一句，
  跟播视频没有意义，所以这条链路固定用云端；不想花钱就别开这个开关，普通转写仍然可以切本地模型。
- **句子边界靠静音**。连说不停时（直播、唱歌）会在 12 秒处硬切，可能切在词中间，
  原文还是完整的，只是分两行。

## macOS：BlackHole

1. 装 [BlackHole 2ch](https://existential.audio/blackhole/)（免费，`brew install blackhole-2ch` 也行）。
2. 打开「音频 MIDI 设置」（应用程序 → 实用工具）→ 左下角 `+` → **创建多输出设备**。
3. 在这个设备里勾上**你的扬声器**和 **BlackHole 2ch**（BlackHole 要勾「漂移校正」里那个主设备选扬声器）。
4. 系统设置 → 声音 → 输出，选这个「多输出设备」。
5. 回到插件：设置 → 播客 →「实时字幕（系统声音）」→ 点「检测设备」→ 输入设备选 `BlackHole 2ch` → 保存。
6. 顶栏点「实时字幕」，然后随便放点声音。

这样你**照常能听到声音**，同时 BlackHole 拿到一份副本给插件。

## Windows：VB-Cable 或立体声混音

两条路选一条：

- **VB-Cable**（推荐，所有声卡都能用）：装 [VB-CABLE](https://vb-audio.com/Cable/)，
  然后系统设置 → 声音 → 输出选 `CABLE Input`；想自己也听到声音，就在「声音控制面板」里
  把 `CABLE Output` 设成「侦听此设备 → 播放到你的扬声器」。
- **立体声混音**：Realtek 声卡在「录音设备」里右键显示已禁用设备，启用「立体声混音」。
  HDMI / USB 声卡通常没有这一项。

然后在插件里选 `CABLE Output` 或「立体声混音」。

## macOS 14.2+：不需要虚拟声卡（推荐）

在 `macOS 14.2` 及以上，插件会用 **Core Audio 进程采集（process tap）** 直接听电脑正在播放的声音，
**不需要装 BlackHole，也不需要建多输出设备**。

- 第一次点「实时字幕」会编译一个几十 KB 的采集 helper（约 5~10 秒），随后弹一次
  「Podwave 想要录制电脑正在播放的声音」——**允许一次即可**。
- 授权位置：系统设置 → 隐私与安全性 → **录屏与系统录音**（不同系统版本叫法略有差异）。
- helper 装在 `<数据目录>/bin/PodwaveAudioTap.app` 的**固定路径**，升级插件不换路径，不会反复弹授权。
- 想看它到底有没有在录：控制面板的**输入电平条**。一直不动就是没授权或系统静音。

设置 → 播客 →「实时字幕（系统声音）」里的**采集方式**：

| 选项 | 行为 |
|---|---|
| 自动（默认） | 系统音频可用就用它，起不来（老系统 / 没权限 / 编译失败）自动退回虚拟声卡 |
| 只看系统音频 | 只用 tap；失败就报错，不悄悄换设备 |
| 虚拟声卡 / 麦克风 | 走原来的 `getUserMedia`（BlackHole / VB-Cable / 麦克风） |

macOS 13.5–14.1、Windows、Linux 上仍然需要虚拟声卡（Windows 的 WASAPI 直采还在计划里）。

## 字幕显示内容与两种字号

字幕框里只有两种字，各管各的字号：

| 显示内容 | 出现什么 | 用哪个字号 |
|---|---|---|
| 原文 + 译文（默认） | 白色大字 = 原文，下面一行灰字 = 译文 | 原文用「原文字号」，译文用「译文字号」 |
| 仅原文 | 只有白色原文，没有灰字 | 原文字号 |
| 仅译文 | 只有译文，白色 | 译文字号 |

- 两种字号在 **设置 → 播客 → 实时字幕** 里分别调（原文 12–42，译文 10–42），拖动即时生效。
- 框右上角 `⚙` 的快捷面板里也有「原文」字号和显示模式切换。
- 不会再出现「上一句」「滚字草稿」之类的第三种灰字；还没识别出内容时用草稿占位，只占一行。

## 独立置顶窗（macOS）

点「实时字幕」之后，屏幕上只出现**一块**字幕框——它也是这次监听的全部界面，页面上不会再冒出第二块。

**平时**它只有字幕：原文 + 译文，上面一句更小更淡。

**鼠标移到框上**，右上角浮出一个小按钮（140ms 淡入）：

| 按钮 | 作用 |
|---|---|
| `✕` | 结束这次监听：按「停止时保存字幕」的设置直接存或丢，**不会再弹「保存吗」** |

外观（不透明度 / 字号 / 宽度）和「停止时保存字幕」都在 **设置 → 播客 → 实时字幕** 里：

- 不透明度 15%~100%，**只作用于底板**，文字永远纯白不透明。
- 字号 12~42、宽度 380~1200。
- 拖动滑块**即时生效**，正在显示的字幕框立刻变（不需要重启监听）。
- 拖动框任意位置可以挪，位置会记住；出现在所有 Space 和全屏应用之上，且不抢焦点。

没有 swiftc 或不是 macOS 时，会自动退回 DSH 页面里的浮层，并提示原因。

## 没出字幕？先看电平条

控制面板上有一条**输入电平**：说话时有声音就会跳动。

- **电平不动** → 系统输出没走虚拟声卡。macOS 要在「音频 MIDI 设置」里建「多输出设备」（扬声器 + BlackHole 2ch），
  然后把系统输出切到它；只选扬声器的话插件听不到任何声音。静音超过 6 秒面板上也会直接这么提示。
- **电平在动但没字幕** → 多半是 API key 或网络，面板底部会显示具体错误。

## 停止时保存

停止会问一次「保存这次字幕？」：

- 保存 → `<数据目录>/live/<会话 id>.json|.srt|.md`，Markdown 里原文和译文交替（适合直接贴笔记）；
- 不保存 → 直接丢掉，只在内存里存在过。

会话不落盘是刻意的：实时字幕多数是「看完就完」，没必要每次都堆文件。

## 常见问题

**字幕一直不动 / 显示「等着听…」**
说明采集到的全是静音：系统输出没走虚拟声卡（macOS 忘了选多输出设备、Windows 选了 CABLE 但
没设侦听），或者音量太小。先在系统里确认有声音，再点「检测设备」重选。

**提示没有 AudioWorklet**
插件会用 `ScriptProcessorNode` 兜底，一样能采，只是更耗 CPU 一点。

**字幕比声音慢几秒**
一句说完才开始识别，加上接口往返，通常落后 2~4 秒。这是「切句 → 识别 → 翻译」这条链路的固有延迟，
不是 bug。

**一句话被切成两半**
600ms 以内的停顿会被当成句子边界。演讲、直播里这是常态；如果太碎，可以把设置里的
`live.silenceMs`（默认 600）调大，但字幕会更慢。

**想调成本**
识别按音频时长计费，和音量无关；一小时 ¥0.4 左右。翻译按 token，一句一行，通常比识别便宜。
