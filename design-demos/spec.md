# 实时字幕 · 最终交互规格（用户拍板）

用户原话：「我点击实时字幕，就出来一个字幕框，然后有一个设置按钮，可以让我设置这些。
这个设置按钮平时是隐藏的，只有在我鼠标移动上去的时候才会显示。」

## 唯一入口
点顶栏「实时字幕」→ 屏幕上出现**一个**字幕框。页面上不出现任何第二块字幕或控制面板。

## 框内结构（框里只有字幕）
```
┌────────────────────────────────────────────┐
│  原文（当前一句）                        ✕ │ ← 悬停才出现
│  译文                                      │
│  上一句（更小更淡）                        │
└────────────────────────────────────────────┘
```

- **平时**：只有字幕，没有按钮。
- **鼠标移上去**：右上角浮出 `✕`（停止），140ms 淡入。
- **点 ✕**：结束监听，按「停止时保存字幕」直接存或丢，不再弹「保存吗」。
- 不透明度 / 字号 / 宽度 / 是否保存，**全在 设置 → 播客 → 实时字幕 里**；拖动即时生效。
- 拖动框任意位置可移动，位置记住。

## 为什么这样
- 一块框 = 一个注意力焦点，不会出现「两个框」。
- 设置收进框里，不占页面、也不需要跳设置页；悬停才出现，静看字时不干扰。
